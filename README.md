# 🌐 Web Lab Experiments

A collection of web development lab experiments built with HTML and CSS, with a dashboard home page that links to all ten experiments.

## 📂 What's Inside

| Folder | Contents |
| --- | --- |
| `index.html` | Dashboard home page linking all experiments |
| `experiment1/` – `experiment10/` | Individual lab experiments, each a small self-contained web page exercise |

## 🚀 How to View

No build step needed — these are static pages.

1. Clone the repository
2. Open `index.html` in a browser (or serve the folder with any static server, e.g. `npx serve .`)
3. Pick an experiment from the dashboard

## 🛠️ Tech Used

- HTML5
- CSS3
- Google Fonts (Inter)
